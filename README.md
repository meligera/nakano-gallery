# nakano-gallery

My little React app showcasing my wallpaper collection from anime The Quintessential Quintuplets (五等分の花嫁).

## Live sites

- GitHub Pages: https://meligera.github.io/nakano-gallery/
- Original deployment: https://nakano-gallery.misatolab.ru

The GitHub Pages site is built and deployed automatically from `main` by the `Deploy gallery to GitHub Pages` workflow.
